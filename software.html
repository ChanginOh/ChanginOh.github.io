Toroidal Search Algorithm (TSA)

Global Optimization

A population-based global optimization algorithm inspired by the topology of a torus. TSA treats bounded search spaces as periodic domains and uses toroidal search dynamics to mitigate stagnation near search space boundaries.

Global Twist Angle

Molecular Geometry

A computational method for quantifying the global backbone twist of cyclic peptides. The algorithm provides a geometric measure for characterizing and comparing the overall twisted conformations of cyclic molecular structures.

Gradient Descent-based Multiclass Harmonic Linear Discriminant Analysis (GDHLDAi)

Dimensionality Reduction

An improved implementation of gradient descent-based multiclass harmonic linear discriminant analysis for supervised dimensionality reduction. GDHLDAi optimizes an orthonormal projection on the Stiefel manifold to identify low-dimensional coordinates that enhance separation between multiple classes.
